## Open GL Applications

Just some simple applications I made using opengl and SDL/X11. The applications
were made over the course of about 2 years while working and studying. I followed
the learnopengl.com tutorials, which are an excellent resource. I chose to use C
for all of them since it would prevent me from just blindly copying and pasting.

I used Cglm for the vectors and matricies as well and some transform operations.
As a goal I would like to make a simple statically linked library that can be
used to show animations (in the engine folder).

I chose to make separate folders for each iteration since I changed quite a bit
between them and it makes it slightly easier than navigating different commits to
try and find the working versions.

# Triangle

This application just shows a rectangle (two triangles) with a fun shader
applied to it. I used it to make sure all the libraries were working correctly.
I used to use shadertoy a lot in highschool making ray marchers and such so it
was fun to return to graphics programming and find that old skill useful.

# Text

I had started learning opengl out of fascination for how gpus and renderers work
but started taking it more seriously when I was tasked with making a digital probe
tester for Solartron probes which now sits in the metrology lab at versatile
technologies (the probe box is mostly unused), with a label on it saying
"The Thing In The Lab". Part way through designing the UI I was asked to use
vulkan instead, so the code was scrapped, it was still interesting to learn how
gpus draw text though. It reminded me of when I was trying to make game engines
using javascript in year 7, where you could load an image into the DOM then 
select specific regions out of it to draw so I would draw the sprite sheets in MS
paint and make little animations of people walking or bouncing a ball.
